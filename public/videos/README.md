# Videos Folder (`public/videos/`)

Drop your `.mp4` or `.webm` video files here!

### Example:
If you save a file called `my-edit.mp4` in this folder:
In `src/data/portfolioData.ts`, set:
```typescript
videoUrl: "/Google Drive - Mininimal motion design.mp4",
thumbnail: "", // Leave empty for automatic frame at 0.5s!
```
