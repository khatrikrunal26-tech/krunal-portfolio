# Thumbnails Folder (`public/thumbnails/`)

Drop your custom `.jpg` or `.png` cover photos here!

### Example:
If you save a cover called `cover-1.jpg` in this folder:
In `src/data/portfolioData.ts`, set:
```typescript
thumbnail: "/thumbnails/cover-1.jpg"
```
*(Note: You can also leave `thumbnail: ""` empty and the website will automatically capture the video frame or YouTube cover for you!)*
